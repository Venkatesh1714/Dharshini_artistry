# Dharshini Artist Website

A responsive single-page website for:
- Mehendi Artist
- Pencil Artist
- Makeup Artist

## Files

- `index.html` - website content
- `style.css` - design/responsive styling
- `script.js` - mobile menu + current year
- `assets/` - add your own images here

## Add your images

Put your images inside `assets/` using these exact names:

- `hero.jpg`
- `mehendi-1.jpg`
- `mehendi-2.jpg`
- `mehendi-3.jpg`
- `pencil-1.jpg`
- `pencil-2.jpg`
- `makeup-1.jpg`

You can add more images by editing the gallery section in `index.html`.

## IMPORTANT: Instagram DM link

Open `index.html` and find:

`https://www.instagram.com/dharshinis_artistry?stkn=YmFjcHRmeDNhcTR5`

Replace `dharshinis_artistry` with the actual Instagram username.

Example:

`https://www.instagram.com/sridevi_mehendi/`

The **Message me on Instagram** button will then open the Instagram profile.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and the complete `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.
7. GitHub will give you the website URL.
